# 万能视频下载网站 - 需求分析文档

> 创建时间：2026-07-15
> 版本：v1.0（MVP）

---

## 一、项目背景

### 1.1 用户痛点
- 许多视频平台不提供下载功能，或下载流程繁琐
- 部分平台限制清晰度、限制批量下载
- 移动端下载体验差，缺乏统一工具
- 用户存在视频总结、字幕翻译等增值需求

### 1.2 项目目标
打造一个**支持多平台、操作简单、移动端友好**的万能视频下载网站，并提供付费增值服务。

---

## 二、目标用户

| 用户类型 | 场景 | 核心需求 |
|---------|------|---------|
| 普通用户 | 想保存喜欢的视频到本地 | 快速下载、操作简单 |
| 内容创作者 | 需要下载素材进行二次创作 | 高清下载、多平台支持 |
| 学习者 | 离线观看教程/课程视频 | 下载 + 字幕翻译 |
| 移动端用户 | 手机上看视频想保存 | 移动端适配、不需安装 App |

---

## 三、功能范围

### 3.1 MVP 核心功能（当前阶段）
| 功能 | 描述 | 优先级 |
|------|------|--------|
| URL 解析 | 输入视频链接，自动识别平台和视频信息 | P0 |
| 视频信息展示 | 展示标题、时长、封面、可用清晰度列表 | P0 |
| 视频下载 | 选择清晰度后下载视频到本地 | P0 |
| 下载进度 | 实时显示下载进度 | P0 |
| 响应式设计 | 桌面端 + 移动端都能正常使用 | P0 |

### 3.2 后续增值功能
| 功能 | 描述 | 优先级 |
|------|------|--------|
| AI 视频摘要 | 用 DeepSeek 对视频内容做总结 | P1 |
| 字幕翻译 | 自动翻译视频字幕 | P1 |
| Stripe 付费 | 月付/年付订阅，解锁高级功能 | P1 |
| 批量下载 | 支持多个链接批量下载 | P2 |
| 下载历史 | 记录用户的下载历史 | P2 |

### 3.3 不做的事情
- 不做用户注册/登录系统（MVP 阶段）
- 不做视频存储服务（下载完即清理）
- 不破解 DRM 保护的内容
- 不支持盗版内容分发

---

## 四、平台支持

基于 yt-dlp 开源项目，支持 **1000+** 视频平台，包括但不限于：

| 平台 | 类型 |
|------|------|
| YouTube | 视频网站 |
| Bilibili | 视频网站 |
| TikTok/Douyin | 短视频 |
| Twitter/X | 社交媒体 |
| Instagram | 社交媒体 |
| 其他 1000+ 平台 | — |

---

## 五、非功能需求

| 需求 | 说明 |
|------|------|
| 性能 | 下载进度实时推送（WebSocket），页面响应 < 2s |
| 安全 | URL 输入校验，防止命令注入 |
| 合规 | 仅用于个人学习目的，尊重版权 |
| 可维护 | 代码结构清晰，yt-dlp 通过 subprocess 调用，不修改源码 |

---

## 六、风险与注意事项

| 风险 | 应对措施 |
|------|---------|
| 平台封号 | yt-dlp 是合法开源工具，项目仅提供技术能力，不鼓励盗版 |
| 法律风险 | 页面添加版权声明，提醒用户尊重版权 |
| yt-dlp 更新 | 通过 pip 管理版本，定期更新 |
| 大文件下载 | 限制单文件大小，设置超时时间 |
